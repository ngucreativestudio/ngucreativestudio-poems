# Poems / How to contribute

This folder stores poem files in Markdown format. To add a poem:
- Create a new Markdown file inside `poems/` (e.g., `poems/my-poem.md`)
- Use a top-level title (`# My Poem`) and add metadata if needed.
- Open a pull request describing the poem and any attribution.

Examples:
- `poems/ode-to-silence.md`

If you'd like, I can also add a simple index generator script later.
